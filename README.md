# Package_Release

Public tagged releases of the `com.quang.*` Unity packages.

Install a package by tag in `Packages/manifest.json`:

```json
"com.quang.base": "https://github.com/Quangbipi/Package_Release.git?path=Packages/com.quang.base#<release-tag>"
```

List every `com.quang.*` dependency explicitly; see `release-index.json` for the versions in each release.

Derived, with permission, from [HeldenChill/Package_Release](https://github.com/HeldenChill/Package_Release).
